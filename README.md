# react-portfolio

My React Portfolio
This is my personal portfolio website built with React.js. It showcases my skills, projects, and contact information in a simple, user-friendly design.

Features
Responsive design for both desktop and mobile.

Smooth navigation using React Router.

Styled with Tailwind CSS for a modern look.

Technologies Used
React.js
CSS
